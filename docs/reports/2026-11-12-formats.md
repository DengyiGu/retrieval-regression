# Retrieval-file interoperability and provenance audit — 2026-11-12

## Outcome

Version 0.2.0 accepts original BEIR judgment TSV and strict TREC judgment/run files directly.
It checks row-level data integrity before scoring and can retain a portable evaluation manifest.
The existing JSON defaults, metric semantics, quality gates, and result schema 1.0 are preserved.
This closes a practical integration gap: users can compare normal exported retrieval files
without writing custom conversion code or silently discarding malformed rows.

The release adds 55 correctness/integration/reference cases. All 129 tests, the standalone
pytest example, lint, formatting and strict source typing passed locally. Packaging and observed
remote CI evidence are recorded in [the verification record](verification-0.2.json).

The [observed GitHub CI run](https://github.com/DengyiGu/retrieval-regression/actions/runs/43380255507) passed all nine jobs on commit
`46aeccc`: Windows/Linux on Python 3.10-3.13, plus independent-reference,
source-archive and isolated installed-wheel validation.

## Real-data format audit

The audit reads the original `scifact/qrels/test.tsv` member from the checksum-verified BEIR
SciFact archive, rather than recreating the BEIR file from the new parser. It exports the saved
fixed BM25 and TF-IDF runs into six-column TREC files, 30,000 rows each. No model tuning or
retrieval improvement is performed in this audit.

- Original BEIR judgments: 300 test queries, 339 judged query/document pairs.
- Archive SHA-256: `536e14446a0ba56ed1398ab1055f39fe852686ecad24a6306c80c490fa8e0165`.
- Parsed BEIR and TREC judgments exactly match the saved JSON judgments.
- Parsed TREC runs exactly match the saved JSON scores and document IDs.
- Complete comparisons, including diagnostics, groups, gates and seeded bootstrap intervals,
  match exactly across the JSON API, file-adapter API and CLI.
- BM25 NDCG@10 remains 0.6696927030; TF-IDF remains 0.6279652523. The same 0.02 absolute-drop
  budget fails as expected, because the measured drop is 0.0417274507.
- All 12 aggregate metrics per natural run match `ir-measures`/`pytrec-eval-terrier` within
  6.661338147750939e-16 absolute error. Reference labels are explicitly represented as integers,
  as required by that tool; no fractional judgment is truncated in this integer-label dataset.

A separate seeded graded reference test uses the independent tool's own TREC file readers and
checks each query's metrics. It covers graded relevance beyond SciFact's binary labels.

### Corruption and missing-query checks

Appending an existing document to the full 30,000-row BM25 file is rejected at line 30,001.
A mixed experiment tag is also rejected at line 30,001. A score/rank contradiction is rejected
at line 2, and a non-finite score at line 1. Unit tests also cover malformed headers/columns,
repeated ranks, unsupported grades, encoding failures, interleaved queries and rank gaps.

A separately labeled faulty TREC export omits every tenth query in sorted order, 30 of 300.
Parsing succeeds because an omitted query is a valid retrieval failure. Evaluation still uses
all 300 judged queries and the no-drop gate detects the regression. This distinguishes an
invalid file from a valid file containing a poor or incomplete retrieval result.

The [complete compact audit](formats-audit-summary.json) contains source-file fingerprints,
archive identity, file hashes, result fingerprints, configuration and the actual rejection lines.
Raw archive, run files and detailed reports remain under ignored `data/` and `reports/` paths.
Original dataset terms and provenance are described in [the first experiment](2026-11-12-validation.md).

## Traceability

`--manifest` records input role/name/format/size/SHA-256, evaluator and Python versions,
parameters and a canonical result SHA-256. Gates and group files are included. It omits absolute
paths and distinguishes comparisons with configured quality gates from ungated calculations.
Inputs are hashed before parsing and after evaluation; changed contents abort before output.
The original input files and external model configuration still need to be retained separately.
The checks are not an atomic filesystem snapshot against adversarial changes.

## Local scale profile

Seeded synthetic inputs use 100 retrieved documents per present query, 10% missing queries,
K=[5,10], three timing repetitions, one warmup and a separate traced-allocation pass. The
measurements time evaluation only, excluding input construction, hashing and traced execution.

| Judged queries | Median seconds | Separate peak traced bytes |
| ---: | ---: | ---: |
| 100 | 0.007197 | 431,722 |
| 1,000 | 0.074929 | 4,411,204 |
| 10,000 | 0.787840 | 44,067,640 |

These are observations from one Windows/Python 3.11.3 environment. Traced allocations do not
include the prebuilt input dictionaries and are not total process memory. The 10,000-query run
contains 900,000 retrieved query/document pairs; it does not establish streaming or million-query
scalability. No speedup or evaluator optimization is claimed. Complete repetitions, seeds,
input/source hashes and environment information are in [the scale record](scaling-0.2-summary.json).

## Reproduce

```console

python scripts/check.py
python benchmarks/scifact.py --download
python benchmarks/audit_formats.py
python benchmarks/benchmark_evaluator.py --queries 100 --documents 100 --repeats 3
python benchmarks/benchmark_evaluator.py --queries 1000 --documents 100 --repeats 3
```

After the archive is cached, rerun `benchmarks/scifact.py` without `--download`. On Windows use
`.venv/Scripts/python.exe` when the environment is not activated. Each scale command overwrites
the default local synthetic output; use `--output` to retain all three records.

## Limits and next work

The adapters intentionally enforce a documented strict profile, including one tag, positive
unique ranks and non-negative integer file grades; certain historical TREC variants are rejected.
See [the format contract](../API.md#file-format-profiles). Parsers retain complete dictionaries;
this is incremental file reading, not a streaming evaluator. HTML still renders all queries.

Evidence still covers one English scientific domain and two lexical systems. Priorities remain
larger/deeper-run profiling, bounded/selectable report views, another domain and a pinned neural
retriever where useful, plus feedback from actual integrators. No neural model gains, production
adoption or PyPI publication are claimed.
