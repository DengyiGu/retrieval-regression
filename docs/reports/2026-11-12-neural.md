# Neural reranking and negative-sampling ablation — 2026-11-12

## Delivered capability

Version 0.3.0 adds a reusable batched `rerank` interface without importing any model framework
into the runtime core. The optional source experiment supplies a real Transformer scorer,
one-epoch adaptation under two sampling conditions and a usable local neural-search command.
The experiment ran locally on an RTX 4090 Laptop GPU; no hosted training service was used.

## Fixed model and procedure

- Model: [cross-encoder/ms-marco-MiniLM-L6-v2](https://huggingface.co/cross-encoder/ms-marco-MiniLM-L6-v2),
  22,713,601 parameters, pretrained for English MS MARCO reranking; Apache-2.0 weights.
- Revision: `233902d25c440f23af6f7d6e94d2946bac0bee0a`. Model safetensors SHA-256:
  `821d1aa69520101d6e0737f78a042ae25b19e5cb9160701909d10434f4aeb0ae`.
- BM25 supplies the same 50 candidates to each model. Model maximum sequence length is 256;
  inference batch size 32, full float32, eager attention, fixed seed 42.
- Adaptation: AdamW, learning rate 2e-5, weight decay 0.01, gradient clipping 1.0, batch 16,
  one epoch. BCE-with-logits uses the same positives and negative counts in both conditions.
- Conditions: unchanged pretrained model; uniform random negatives; top BM25 hard negatives.
  All known positive documents for a training query are excluded from its negative pool.
  Unjudged negatives are weak training labels, not verified irrelevant documents.

The configuration was saved before model evaluation. Identity records retain configuration,
archive, source and checkpoint hashes. Source work was uncommitted during execution; that dirty
state is retained and source fingerprints identify the implementation. The fixed configuration
and actual software versions are in [the complete compact record](neural-summary.json).

## Leakage control and model selection

SciFact supplies 809 official training queries and 300 official test queries. IDs do not overlap,
but two training queries exactly match normalized test query text. They were removed before
sampling. Remaining queries were grouped by NFKC/casefold/whitespace-normalized text and assigned
by seeded hash: **727 training, 80 validation, 2 excluded**. No identical normalized query text
crosses the retained training/validation/test partitions. Semantic paraphrase overlap is not ruled out.

Each adaptation condition trained on 3,336 pairs: 834 positive pairs and 2,502 weak negatives,
209 optimizer steps. Test relevance labels were not used for training pairs or model selection.
Selection used training-derived validation NDCG@10 only:

| Variant | Validation NDCG@10 |
| --- | ---: |
| Pretrained | 0.640303 |
| Random-negative adaptation | 0.677952 |
| Hard-negative adaptation | 0.676027 |

The selected variant was random-negative adaptation. All variants were then retained in the
reported test results. No hyperparameters were changed in response to those test results.

## Held-out results

| Dataset | BM25 | Pretrained reranker | Random-negative adaptation | Hard-negative adaptation |
| --- | ---: | ---: | ---: | ---: |
| scifact | 0.669693 | 0.667796 | 0.698973 | 0.692114 |
| nfcorpus | 0.311354 | 0.332514 | 0.334350 | 0.333439 |

Values are NDCG@10. SciFact has 300 test queries, 5,183 documents and 339 judgments. NFCorpus
has 323 test queries, 3,633 documents and 12,334 judgments. NFCorpus is an external collection
with medical/nutrition information needs; these two collections do not establish broad coverage
of languages or domains.

On SciFact, random-negative adaptation improves over pretrained by 0.031177 absolute; the
1,000-sample paired-bootstrap descriptive interval is [0.017401, 0.046703]. Hard-negative
adaptation improves by 0.024317, interval [0.005606, 0.044922]. These intervals depend on query
sampling assumptions, do not account for multiple comparisons and are not causal proof.

On NFCorpus, corresponding NDCG@10 differences are only +0.001836 and +0.000925; both intervals
include zero. Random-negative adaptation also reduces NDCG@1 by 0.026316 and MRR@10 by 0.009989.
Thus this run shows a useful in-domain change but does not demonstrate a reliable external gain.
Hard-negative sampling is not automatically superior in this small, fixed one-epoch experiment.

The predeclared NDCG@10 maximum-drop budget of 0.02 passes for the reported comparisons.
A separate **post-hoc**, unused-for-selection NDCG@1 drop check at 0.02 fails for the NFCorpus
random-negative variant. This illustrates why a single acceptance metric can conceal tradeoffs.

## Actual compute and functional use

Random-negative training took 11.76 seconds and hard-negative training 15.35 seconds, excluding
checkpoint saving, preparation and validation. Each peaked at 1,703,660,544 bytes (~1.59 GiB)
of PyTorch-allocated GPU memory; this excludes CUDA/driver reservations and other applications.
These are small-model, one-epoch measurements on one laptop, not large-model training claims.

Scoring 15,000 SciFact query/document pairs took 14.47–20.90 seconds across variants; scoring
16,150 NFCorpus pairs took 16.02–20.26 seconds. Timers include tokenization and model scoring
after a single-example warmup, exclude loading/candidate retrieval, and do not constitute a
controlled throughput comparison. The same architecture is used across variants.

`python -m examples.neural_search` was exercised using the selected local checkpoint and cached
SciFact corpus. Results include document titles/snippets, new scores and original BM25 ranks.
This is a search capability, not an answer-generation or clinical guidance system.

## Verification and reproduction

All 96 aggregate metric values across two datasets and four systems matched an independent
`ir-measures`/`pytrec-eval-terrier` oracle within 6.7e-16 absolute error, after aligning score-tie
ordering. An optional CPU torch smoke test also confirmed the training loop updates weights and
learns separable pairs; the full GPU run above is the substantive model evidence.

See [experiment instructions](../../experiments/reranking/README.md) for installation and commands,
[fixed configuration](../../experiments/reranking/config.json)
for core tests, package installation and the observed CI status. Checkpoints, datasets, pairs,
full runs and reports stay under ignored local paths.

The [observed GitHub CI run](https://github.com/DengyiGu/retrieval-regression/actions/runs/43386371333) passed all nine jobs on commit
`b9ea617`: Windows/Linux on Python 3.10-3.13 and independent-reference/package checks.
CI validates the lightweight API and integration surfaces; the GPU experiment was executed
locally as reported above, rather than on GitHub's hosted runners.

- NFCorpus source: https://www.cl.uni-heidelberg.de/statnlpgroup/nfcorpus/ . It permits academic

- Pretrained weights retain their source license; the repository's MIT code license does not
  relicense data or weights.

This is one seed, one epoch per condition, one small model and two related English collections.
Judgments are incomplete; hard negatives can be false negatives. Corpus or model-pretraining
contamination is not ruled out. Candidate depth/truncation constrain attainable scores. Larger
multi-seed, multilingual and different-model comparisons remain future experiments.
