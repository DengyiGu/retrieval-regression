# Correctness and usefulness review — 2026-11-12

## Assessment

The 0.1.0 alpha provides a working regression check for teams that already export retrieval
rankings and maintain relevance judgments. It can reject a proposed retrieval change in pytest
or CI, retain missing queries in the scoring denominator, and report affected categories and
queries. Its useful contribution is the integrated testing workflow, not new retrieval metrics.

[ir-measures](https://ir-measur.es/en/latest/) offers a broader set of evaluation measures and
input integrations. [BEIR](https://github.com/beir-cellar/beir) provides datasets and retrieval
benchmarks. [LlamaIndex](https://developers.llamaindex.ai/python/examples/evaluation/retrieval/retriever_eval/)
also evaluates retrievers within its framework. These established alternatives mean that this
project should be chosen for its small, framework-independent regression workflow rather than
for metric novelty. This comparison describes documented scope, not a measured superiority claim.

No external adoption study or production deployment has been performed. The project demonstrates
Python package engineering, evaluation correctness, test integration, and reproducible validation.
It does not yet demonstrate neural retrieval research or production-scale operations.

## Defects reproduced and fixed

Six new regression cases failed on the previous implementation and passed after the fixes.

| Defect | Observed failure | Corrected behavior |
| --- | --- | --- |
| Input hard-link alias | A report could overwrite an input through a different filename | Compare file identity as well as resolved paths before writing |
| Report hard-link aliases | JSON and HTML could overwrite the same underlying file | Reject aliased destinations with exit code 2 |
| JSON exponent overflow | `load_json` accepted `1e309` and `-1e999` as infinities | Reject non-finite float conversions during parsing |
| Ungated HTML status | No thresholds still displayed a prominent PASS | Display NOT CONFIGURED; preserve the documented API semantics |
| Legacy stdout encoding | Valid Chinese/emoji query IDs caused a CLI error | Emit ASCII-escaped JSON on stdout; keep report files UTF-8 |

The parser issue affected the strict loader contract; evaluation already rejected non-finite
scores and grades. File-identity checks cover existing aliases at validation time, not adversarial
concurrent filesystem changes. The API's `passed=True` with empty `gates` still means no gate
failed, not that a quality requirement was enforced.

CI now installs the built wheel in an isolated environment, exercises its API and CLI without
runtime dependencies, then installs the pytest extra and verifies automatic fixture discovery.
Previously that installation smoke check was only run locally. Source distributions are also
checked against the Git index to reject accidentally bundled local files from stale build metadata.

## Public-data replay

The complete cached SciFact archive was rerun offline from a clean implementation checkout,
with the same fixed parameters and no new tuning. All aggregate metrics and the missing-query
fault results reproduced exactly. The test set contains 300 queries, 5,183 documents, and 339
relevance judgments.

| Check | Result |
| --- | ---: |
| BM25 NDCG@10 | 0.6696927030 |
| TF-IDF NDCG@10 | 0.6279652523 |
| Candidate minus baseline | -0.0417274507 |
| Configured maximum absolute drop | 0.02 |
| Natural comparison gate | FAIL, as expected from the measured drop |
| Maximum independent-reference error | 6.661338147750939e-16 |
| Deliberately omitted queries | 30 / 300, detected without dropping the denominator |

The [replay record](scifact-audit-summary.json) retains dataset hashes, source-file fingerprints,
configuration, versions, timing and exact results. The [original experiment report](2026-11-12-validation.md)
explains the dataset, licensing, incomplete judgments, and the deliberately injected fault.

## Remaining limits

- JSON/Python mappings only; strict BEIR TSV and TREC file adapters remain planned.
- Evidence covers one English scientific dataset and two lexical retrievers.
- No PyPI release, neural retriever comparison, or demonstrated external user adoption.
- No streaming or production-scale memory/latency validation.
- Judgment mappings must be updated externally if document IDs or chunk boundaries change.
- Reported bootstrap intervals are descriptive; gates are policy thresholds, not significance tests.

The current alpha acceptance criteria are met. The larger roadmap is not complete, and passing
these checks does not prove the absence of defects. The next useful milestone remains input
interoperability, followed by feedback from users integrating real retrieval pipelines.
